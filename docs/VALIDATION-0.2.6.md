# 雨课助手 Android 0.2.6 修复与验证

日期：2026-10-20（北京时间）。versionCode 8，包名 `cn.yukehelper.android.prototype`，Android 8.0+，Target SDK 35。

## 问题与修复

用户确认：课堂仍在进行，也能收到新消息，但 0.2.5 显示“课堂消息连接持续中断”。仅凭截图不能确定手机上每次断开的原因，也不能据此认定平台或手机网络故障。

本地在 0.2.5 上通过两项新增回归测试复现了实际缺陷，修复后通过：

1. 每次连接只保持 5 秒但持续收到题目消息，仍因未达到 10 秒稳定门槛而累积失败并误报。现在收到有效课堂事件或状态更新即确认恢复；只有 hello 的安静连接仍等待 10 秒，短暂 hello 后立即断开的退避继续保留。
2. 主动刷新失败前直接丢弃原凭据，使本可以继续接收消息的连接停在刷新步骤。现在保留原凭据，主动刷新失败后尝试继续连接；服务端已明确拒绝的凭据不会用于回退，账号登录失效仍正常停止监测。

有效课堂事件也可以确认连接就绪，避免 hello 缺失或延迟时反复超时断开。未知消息和空消息不作为就绪依据。

HTTP、DNS、连接、超时、TLS、响应格式异常和未包含课堂凭据等错误保留固定分类，告警标明获取凭据、连接或处理消息的阶段。只展示数值状态码，不包含响应原文、异常原文、完整请求地址、Cookie 或 Token。自动操作积压使用单独的重新同步提示，不在仍接收有效消息时误报网络持续中断。

本次未修改存储格式、账号数据、课程规则或运行依赖，动态二维码签到仍未支持。已有错误历史保留，不会因升级自动删除。
