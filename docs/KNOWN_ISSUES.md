# 已知限制

## 动态二维码考勤

0.2.9 不支持动态二维码识别或动态考勤结果确认。取得课堂连接凭据后显示“已进入课堂；考勤状态请以雨课堂为准”，不能证明教师端已记为签到。0.2.4 及更早版本的“课堂签到成功”文案从 0.2.5 起已修正，详见 [公开资料核实](DYNAMIC_QR_ATTENDANCE.md)。

## 连接提示

有效课堂消息会立即清除中断状态；只有 hello、没有课堂事件的安静连接仍等待 10 秒确认稳定。已连接状态表示收到 hello 或有效课堂消息，不能保证没有网络延迟或遗漏。真实手机上每次断开的原因无法仅凭截图确认；旧版提示可能来自重试状态误报，或被合并显示的其他错误。0.2.6 已补充阶段和固定错误分类，历史记录不会自动删除。

## 入课 HTTP 400

0.2.7 已补充 HTTP 400 错误体内的数值接口代码及已知业务拒绝分类，入课失败不再统一归为消息连接中断。用户在重新登录后仍收到 50400。0.2.8 修复编号类型丢失并增加有条件的一次字符串兼容；用户已反馈该修复在其课堂成功；公开资料仍未找到 50400 的确切定义，不能推广为全部课堂的验证结论。若仍失败，新事件会补充最终编号格式及已识别的校验分类。详见 [入课错误说明](LESSON_ENTRY_ERRORS.md)。

## 设备兼容

最低 Android 8.0 是代码兼容目标，0.2.9 的全局 AI 更新尚未进行实机或模拟器验证。不同 ROM 的后台保活、WebView、TTS、文件选择器及折叠屏切换需要设备验证。系统结束进程后需手动重启监测；每次监测最长 4 小时。

纯 HarmonyOS NEXT 不支持 Android APK。支持安装 APK 的 HarmonyOS / EMUI 环境需按实际版本确认。

## 网络和 AI

平台接口不是本项目控制的稳定服务，接口变更可能影响登录或课堂功能。AI 模型可用性、图片能力及收费由服务商决定；未使用真实 DeepSeek Key 验证 0.2.4 的准确率或延迟。自动测试使用模拟服务器。0.2.9 的 AI 设置由所有账号共用，删除密钥或修改优先顺序会影响全部账号；多个账号会共同消耗对应 AI 服务账户的 API 额度。已开始的调用可能继续使用修改前的配置。

## 签名

本机或 CI 生成的调试密钥可能与已安装 APK 不同。固定签名 APK 只能由持有对应私钥的维护者生成。源码包不含该私钥。
