# 已知限制

## 作业提醒

0.2.12 根据官方公开网页脚本实现只读作业同步，用户已反馈本次作业功能验证成功。反馈未包含逐项测试记录，更多机型、站点、通知及跳转仍需确认。支持课程动态中的普通作业（type 4）和新版练习（type 19），不把课堂题目、考试或通知混为作业。其他资源图谱、学校定制接口及课程章节内独立资源可能暂未覆盖。

自动检查依赖账号与前台监测开启，每轮检查后等待 5 分钟；每次监测最多 4 小时。不是实时推送，也没有截止前闹钟；停止监测、强制停止或系统限制后台时不会自动检查，可在消息页手动同步。每门课程每轮最多检查最近 200 条动态，详情或请求失败会提示并保留缓存；完整分页成功后才隐藏已不在列表中的项目。

普通作业的封面接口常只有标题、题数与限时；新版练习会读取可用文字，图片、附件、复杂排版与完整题目在官方端查看。文字有长度上限，超过 30 个题目的部分会提示前往官方端。缺失/无法识别的时间显示待核对，不能推断老师没有设置截止时间。教师修改内容和接口变更均可能造成延迟或遗漏，以官方端为准。

作业通知不使用 TTS。通知权限、通用规则的作业选项及系统“作业提醒”类别均需开启；缓存成功后即记录去重，通知被系统拦截时可到消息页查看。旧配置升级时增加作业通知类型，但保留已有的通知总开关。

## 动态二维码考勤

0.2.13 起支持动态二维码签到：现场扫码、相册识别或粘贴二维码内容后，用 `/api/v3/app/scan` 换课堂编号，再调用 `/api/v3/lesson/checkin` 提交，仅 `code==0` 显示成功；过期（51203）、未识别（51201/50033）、课堂结束（50004）、频率限制（50025/50029）等按固定分类提示并附数值代码。

仍有限制：动态码由教师端按当次课堂签发、约每 8 秒刷新，内容是带签名的 URL，本 App 只读取现场大屏或用户提供的截图，不生成、不伪造，也无法替代现场取码；开启动态二维码签到后，其他进班渠道仍会被记为未签到。**真实课堂的签到回执尚未在手机上验证**，单元测试只覆盖请求构造、编号类型、错误映射与幂等。获取课堂连接凭据后显示的“已进入课堂”依旧不代表考勤通过。详见 [协议来源与边界](DYNAMIC_QR_ATTENDANCE.md)。

## 连接提示

有效课堂消息会立即清除中断状态；只有 hello、没有课堂事件的安静连接仍等待 10 秒确认稳定。已连接状态表示收到 hello 或有效课堂消息，不能保证没有网络延迟或遗漏。真实手机上每次断开的原因无法仅凭截图确认；旧版提示可能来自重试状态误报，或被合并显示的其他错误。0.2.6 已补充阶段和固定错误分类，历史记录不会自动删除。

## 入课 HTTP 400

0.2.7 已补充 HTTP 400 错误体内的数值接口代码及已知业务拒绝分类，入课失败不再统一归为消息连接中断。用户在重新登录后仍收到 50400。0.2.8 修复编号类型丢失并增加有条件的一次字符串兼容；用户已反馈该修复在其课堂成功；公开资料仍未找到 50400 的确切定义，不能推广为全部课堂的验证结论。若仍失败，新事件会补充最终编号格式及已识别的校验分类。详见 [入课错误说明](LESSON_ENTRY_ERRORS.md)。

## 答题提交未确认

截图中的旧提示没有保留提交失败原因，无法据此确认官方端是否收到答案。0.2.10 修复已复现的题目编号类型丢失，以及第 3 次响应丢失后缺少最终复查的问题，并补充数值错误码、固定分类和编号格式。

数字编号只有在 HTTP 400 / 50400 且没有明确其他校验要求时才改用同值字符串，继续遵守每题最多 3 次提交和每次提交前检查已有答案。该兼容条件沿用入课的本地经验，无法证明截图中的所有提交失败均由此引起；真实课堂效果仍需手机验证。

最终查询失败或服务端尚未显示答案时，保持“提交未确认”，请在官方端核对；不会把单纯发出请求当成提交成功。参见 [本版验证](VALIDATION-0.2.10.md)。

## 设备兼容

最低 Android 8.0 是代码兼容目标，0.2.10 的答题修复尚未进行实机或模拟器验证。不同 ROM 的后台保活、WebView、TTS、文件选择器及折叠屏切换需要设备验证。系统结束进程后需手动重启监测；每次监测最长 4 小时。

纯 HarmonyOS NEXT 不支持 Android APK。支持安装 APK 的 HarmonyOS / EMUI 环境需按实际版本确认。

## 网络和 AI

平台接口不是本项目控制的稳定服务，接口变更可能影响登录或课堂功能。AI 模型可用性、图片能力及收费由服务商决定；未使用真实 DeepSeek Key 验证 0.2.4 的准确率或延迟。自动测试使用模拟服务器。0.2.9 的 AI 设置由所有账号共用，删除密钥或修改优先顺序会影响全部账号；多个账号会共同消耗对应 AI 服务账户的 API 额度。已开始的调用可能继续使用修改前的配置。

## 签名

本机或 CI 生成的调试密钥可能与已安装 APK 不同。固定签名 APK 只能由持有对应私钥的维护者生成。源码包不含该私钥。
