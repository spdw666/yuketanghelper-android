# 作业提醒

0.2.12 在“消息”中提供“作业提醒”和“课堂动态”两个视图。作业按账号保存，跟随课程页的已应用勾选；完整步骤见 [使用说明](USER_GUIDE.md)。不需要填写新的密钥。

## 使用

1. 在课程页勾选课程并应用选择。
2. 到“消息 → 作业提醒”点击“立即同步作业”。查看课程、作业标题、文字要求和截止时间；较长文字可通过“查看作业要求”阅读及复制。
3. 开始监测后，启用账号会在每轮结束后间隔 5 分钟重新检查，课程没有正在上课也会检查。停止监测后可以手动同步。
4. 系统提醒由“通用课程设置 → 本机通知 → 作业”控制；同时需要 Android 通知权限和“作业提醒”渠道开启。点击作业通知会进入对应账号的消息页。
5. 图片、附件、完整题目通过“去雨课堂查看”打开对应官方页面，浏览器可能需要自行登录。跳转地址不附带会话或密钥。

首次同步会为尚未截止的作业生成消息。后续只有新作业、标题/要求/截止时间改变才生成更新消息。第一次遇到已经截止的历史作业只缓存；重新登录同一账号、重启监测或 App 不会重置去重记录。移除账号会删除该账号作业与消息，仍保留全局 AI 配置。

截止时间显示为北京时间，支持接口返回的秒、毫秒、带时区和常见日期字符串。零或明确空值显示“老师未设置截止时间”；字段缺失或格式异常显示“截止时间待核对”。不会根据同步失败推断没有作业。

## 同步边界

- 当前支持课程动态中的普通作业（type 4）和新版练习（type 19），跳过课堂、公告与考试。
- 普通作业通过封面接口读取概况，能够提供的要求可能只有文字说明、题数和限时。新版练习先读取叶子详情，再读取练习列表中的文字要求；图片以文字标记提示。
- 每门课程每轮最多检查 10 页、每页 20 条课程动态；达到限制时明确提示。文字最多约 12,000 字符、练习最多提取 30 个题目的要求，超出时提示到官方端查看。
- 列表请求失败不覆盖缓存；单个详情请求失败保留此前要求与截止时间。只有完整分页成功，才隐藏已不在该列表中的旧项目，保留内部去重记录。
- 同步失败不停止正常的课堂连接；明确登录失效时沿用重新登录流程。手动与自动检查共用账号锁，避免重复请求和提醒。
- 自动检查仍受前台监测、每次 4 小时上限及手机后台管理影响。不是实时推送，没有额外实现截止前闹钟或系统停止后的自动唤醒。

## 接口来源

2026-10-21 读取官方公开网页的下列脚本核实接口参数；没有发送真实登录信息，没有访问真实账号作业，也没有调用开始作业或提交答案接口。

| 官方来源 | 核实内容 |
| --- | --- |
| [网页主脚本](https://fe-static-yuketang.yuketang.cn/fe/static/web/1.2.334/js/pc.3f25ca35.js) | API 前缀、课程动态/作业封面/叶子详情/练习列表路径 |
| [学生课程动态](https://fe-static-yuketang.yuketang.cn/fe/static/web/1.2.334/js/16621.49827055.js) | `actype=-1`、从 0 开始分页、`offset=20`、`sort=-1`、`data.activities` / `has_more`、type 4 / 19、`deadline` / `content.score_d` |
| [学生作业页面](https://fe-static-yuketang.yuketang.cn/fe/static/web/1.2.334/js/35321.61baeff8.js) | `GET /v2/api/web/quiz/quiz_info`，参数 `classroom_id` 与 `quiz_id`，读取封面与开始作业为不同请求 |

当前实现只使用以下读取请求：

```text
GET /v2/api/web/logs/learn/{classroom_id}?actype=-1&page=0&offset=20&sort=-1
GET /v2/api/web/quiz/quiz_info?classroom_id=...&quiz_id=...
GET /mooc-api/v1/lms/learn/leaf_info/{classroom_id}/{leaf_id}/
GET /mooc-api/v1/lms/exercise/get_exercise_list/{exercise_id}/{sku_id}/
```

同一账号的 Session 只发送给其雨课堂站点，沿用 Cookie、Referer 和 `xt-agent: web` 请求头。不会将其传给 AI 或外部图片地址。公开网页实现不属于正式接口稳定性承诺；其他资源图谱和学校定制接口可能暂未覆盖。

## 验证

本地模拟接口覆盖分页、只读请求、账号请求头、异常响应、要求文本、不同截止时间格式、持久化去重、撤回隐藏、取消、登录失效和配置迁移。具体结果见 [0.2.12 验证记录](VALIDATION-0.2.12.md)。用户于 2026-10-21 反馈本次作业功能验证成功，未提供逐项测试记录；其他设备、站点、通知及覆盖安装仍需确认，请在官方端核对同步结果。
