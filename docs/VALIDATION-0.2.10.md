# 雨课助手 Android 0.2.10 答题提交修复与验证

日期：2026-10-20。versionCode 12，包名 `cn.yukehelper.android.prototype`，Android 8.0+，Target SDK 35。

## 问题与修复

用户截图显示“提交未确认，已达到 3 次尝试上限”。旧实现吞掉了提交异常，截图本身无法确认是参数拒绝、响应丢失还是其他故障，官方端是否已收到答案也未确认。

已用两个回归场景复现旧版缺陷：

1. 课件接口返回字符串题目编号时，提交体被强制转换为 JSON 数字；包含长编号及前导零的字符串不能保留原表示。
2. 第 3 次提交被模拟服务接收、但响应丢失后，旧实现不再查询服务器答案，直接显示达到上限。前两次失败后的重试前刷新不覆盖最后一次请求。

本版为题目保存原始 JSON 编号，内部去重继续使用字符串键。数字编号收到 HTTP 400 / 50400，且未识别到明确其他校验要求时，可在下一次提交使用同值字符串；该兼容沿用已有入课经验，不代表已取得 50400 的官方定义。权限、CSRF、缺参、JSON 和数字类型要求不触发转换；已经为字符串时不进行格式转换。

每次重试前仍先查询已有答案，整个过程最多 3 次 POST。最后一次失败后增加只读复查，确认已有答案则保留提交，不追加第 4 次 POST；查询失败或没有答案时保持“未确认”。明确成功仍要求 HTTP 成功且接口 `code=0`。

提交失败现在只保留 HTTP 数值状态、接口数值代码、固定校验分类与编号格式。错误体最多读取 16 KiB，任意上游文本、异常原文、Cookie、Token、AI 密钥及错误响应不会写入事件。明确登录失效仍向上抛出。
