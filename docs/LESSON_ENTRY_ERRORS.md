# 入课错误与 HTTP 400

2026-10-20 后续反馈：用户确认 0.2.8 入课成功。该反馈仅覆盖用户当前课堂；50400 的官方定义仍未知。0.2.9 保留相同入课逻辑，并新增全局 AI 设置。

0.2.8 保留入课编号的原始类型，针对新反馈的 HTTP 400 / 50400 增加有条件的一次字符串格式兼容。0.2.7 引入的独立入课拒绝提示继续保留：首次失败立即提示，每 60 秒重试，同一轮故障每 2 分钟最多提醒一次。课堂列表仍继续刷新，其他课堂继续监测。

HTTP 400 发生在 `POST /api/v3/lesson/checkin` 时，说明获取凭据的请求被拒绝，还没有建立该次课堂消息连接。“正在上课 1、已连接 0”可以同时出现：课堂列表可读不等于已取得入课凭据。

## 50400 与编号类型兼容

用户已确认在 0.2.7 内重新登录后仍出现 50400，同一账号在官方端可以直接进入。公开学生端文案及参考项目的可见问题中未找到 50400 的确切定义，因此不把它直接认定为身份、动态扫码或某个具体参数错误。

进一步核对发现实际协议差异：桌面参考实现把课堂列表中的 `lessonId` 原样传入入课请求；网页端将路由中的 `lessonID` 字符串直接作为 `lessonId`。0.2.7 的解析器则将编号强制转换为 Long，随后序列化为 JSON 数字，丢失了原始字符串表示。

0.2.8 在内部保留数字监测键，同时保存并回传接口中的原始 JSON 编号。字符串编号的类型、数字内容及前导零得以保留。第一次请求使用接口给出的类型；只有数字编号遇到 HTTP 400 / 50400，且没有明确其他校验要求时，才用网页使用的字符串形式额外尝试一次。账号、站点、source 和编号数字内容一致。

已经使用字符串时不重复尝试；HTTP 200 内的 50400 以及其他错误码均不触发兼容。明确提示 CSRF、缺失必填参数、JSON 解析失败或要求数字字段时，也不进行此转换。兼容请求失败后直接上抛，继续沿用每分钟的外层重试，避免立即重复请求。

成功后的消息握手、弹幕与红包请求沿用被接受的编号表示。入课诊断显示最终的“数字 / 字符串”类型；对于标准错误文案，只映射为固定的字段类型、缺参、JSON、参数校验或请求校验类别，不显示任意原文及编号值。50400 的建议改为反馈这些信息。

两项本地模拟服务器测试在 0.2.7 的原有实现上失败，修复后纳入完整测试。它们证明编号类型丢失及格式兼容行为，不证明用户真实课堂的 50400 一定由该差异导致；仍需实机确认。

## 代码含义

以下分类依据公开网页端的错误码文案及入课处理流程，不是平台对第三方提供的稳定接口承诺。同一种业务拒绝无论以 HTTP 200 还是 400 返回，均使用对应的固定分类。

| 接口代码 | 提示与处理 |
| --- | --- |
| 50000、50002、50003 | 当前登录没有资源或课堂访问权限，核对 App 内账号和站点、官方端入课权限 |
| 50027 | 尚未加入班级，在官方雨课堂加入后重试 |
| 50015、50019 | 需要绑定学校身份，在官方端完成绑定后重试 |
| 50017、50018、50020、50021、50022 | 班级限制加入或人数已满，在官方端核对条件 |
| 50004 | 服务端提示已经下课，在官方端核对；等待课堂列表更新 |
| 50070 | 课堂要求动态二维码签到，使用官方雨课堂扫描现场有效二维码 |
| 50025、50029 | 请求频率限制，降低频率后重试 |
| 50400 | 具体含义待确认；适用时尝试一次字符串编号兼容，保留最终编号类型及已识别的固定校验分类 |
| 其他或无代码 | 入课请求被拒绝，具体原因待确认；保留数值代码供反馈 |

HTTP 401/403、明确的登录失效业务代码或登录失效文案继续进入重新登录流程。只读访问未登录的官方公开接口时，实际返回 `code: 50000, msg: UNAUTHENTICATED`，0.2.8 也识别该明确文案。50000 在公开文案中还表示资源或权限问题，因此不会仅凭这一数字删除账号登录。

错误响应最多读取 16 KiB，完整且可识别的 JSON 才提取数值代码。HTML、截断数据、格式变化或读取失败保留 HTTP 400 并显示原因待确认。响应原文、Cookie、课堂 Token、Bearer 及任意服务端消息不写入事件记录。HTTP 400 内即使包含 Token，也不被当作入课成功。

## 更新和反馈

先停止监测，用同一签名的当前版本覆盖安装，再开启监测。若仍有 50400，记录新事件中的 HTTP 状态、接口代码、编号格式、校验分类及站点、版本、发生时间。提供截图时隐去个人信息；无需提供 Cookie、密钥或完整网络响应。

用户已反馈 0.2.8 在其课堂恢复成功，其他环境仍需分别确认。如果兼容后的字符串请求仍被拒绝，新的类型与固定校验提示可帮助继续定位；不会据此自动跳过班级权限、身份或签到要求。
