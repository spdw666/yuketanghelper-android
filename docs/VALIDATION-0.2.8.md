# 雨课助手 Android 0.2.8 编号兼容修复与验证

日期：2026-10-20（北京时间）。versionCode 10，包名 `cn.yukehelper.android.prototype`，Android 8.0+，Target SDK 35。

## 反馈与证据

用户反馈 0.2.7 获取课堂凭据仍返回 HTTP 400 / 接口代码 50400，并确认在 App 内重新登录后仍然出现；同一账号可在官方端直接进入课堂。

公开学生端 3.3.237 的可见错误码文案及参考项目可见问题中未找到 50400 的确切含义。本次没有把它直接归因于登录、动态扫码或某个参数错误。

继续追踪编号处理发现实际协议差异：桌面参考实现从课堂列表原样传递 `lessonId`，网页入课使用路由中的字符串编号；安卓版 0.2.7 则先转为 Long，随后发成 JSON 数字，丢掉原始表示。来源与边界详见 [入课错误说明](LESSON_ENTRY_ERRORS.md)。

本地在修改前的 0.2.7 实现上新增两项 MockWebServer 复现：字符串编号从轮询到入课保留、数字编号被 50400 拒绝后的字符串格式兼容。结果为 2 项失败，均为 LessonEntryFailure。修复后两项通过。模拟服务器契约用于证明本地类型丢失和兼容行为，不能证明用户真实课堂一定因该差异返回 50400。

## 变更

- 内部保留 Long 监测键，网络同时保留接口原始 JsonPrimitive 编号，避免类型或前导零丢失，并约束两者指向同一课堂。
- 首次使用原始类型；仅数字编号遇到 HTTP 400 / 50400 且没有明确其他校验要求时，以相同数字内容的字符串额外尝试一次。账号、站点、source 不变，不更换课堂编号。
- 已为字符串、其他业务拒绝、HTTP 200 业务 50400，以及明确 CSRF、缺参、JSON 解析或数字字段要求，不触发格式兼容。第二次失败上抛，取消正常传播。
- 成功后的消息握手、弹幕及红包保持已接受的课堂编号表示；其他课堂监测和原有操作去重继续保留。
- 失败消息补充最终编号类型及固定的校验类别，不包含任意上游原文、编号值或凭据；50400 的建议改为反馈这些信息。
- 无凭据的公开 GET 实际返回 `50000 / UNAUTHENTICATED`，补充该明确登录失效文案的识别；普通资源权限 50000 不单凭数字退出登录。
