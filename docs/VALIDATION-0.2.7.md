# 雨课助手 Android 0.2.7 入课错误诊断与验证

日期：2026-10-20（北京时间）。versionCode 9，包名 `cn.yukehelper.android.prototype`，Android 8.0+，Target SDK 35。

## 问题与变更

新反馈发生在获取课堂凭据的 HTTP 阶段：请求返回 HTTP 400，当前账号已连接 0 堂课。用户确认同一账号在官方雨课堂可以直接进入。截图没有数值业务错误码，不能确定 HTTP 400 的具体触发原因。

已核对桌面参考实现的参数、域名和基本请求头；与安卓版一致，没有证据表明 `lessonId` 或 `source` 拼写错误。只读核对官方学生端 3.3.237，确认同一入课接口有多种业务拒绝。来源及对应含义见 [入课错误说明](LESSON_ENTRY_ERRORS.md)。

0.2.6 在 HTTP 非成功时先关闭响应，丢掉了其中的接口错误码，随后把所有 HTTP 400 合并为消息连接中断。0.2.7 修复该诊断和处理缺陷：

- HTTP 400 错误响应限量读取 16 KiB，只提取数值代码和固定分类；明确登录失效继续进入重新登录流程。
- HTTP 200 内的入课业务拒绝也采用相同分类。50000 在公开文案中可表示资源或权限问题，不单凭该数字清除账号。
- 首次入课拒绝立即提示，每 60 秒重试，同一轮故障每 2 分钟最多提醒一次。正常课堂继续收消息，停止监测会取消待重试任务。
- 未取得凭据时不报入课成功。HTTP 400 中即使包含 Token 也不作为成功，不记录任意上游消息、响应原文、Cookie、Token 或 Bearer。
- 保留 0.2.6 的有效消息恢复、可用原凭据回退和自动操作去重。

本版没有证明真实课堂已恢复，也未实现动态二维码签到。未知错误保持“具体原因待确认”，需新版实机返回码继续定位。
