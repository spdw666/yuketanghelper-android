# 雨课助手 Android 0.2.7（预发布诊断版）

修正获取课堂凭据返回 HTTP 400 时，丢弃错误码并统一报告为消息连接中断的问题。

## 更新

- 限量读取错误响应，展示数值接口代码及固定分类，区分入班、身份、访问权限、动态扫码要求、下课和频率限制。
- 同时处理 HTTP 200 中的业务拒绝；未知错误保持原因待确认，明确登录失效继续要求登录。
- 入课拒绝首次立即提示，每 60 秒重试，同一轮故障每 2 分钟最多提醒一次；其他课堂继续监测。
- HTTP 400 内的 Token 不作为入课成功，不记录任意上游消息或凭据。
- 保留 0.2.6 的消息恢复、凭据回退和操作去重。

截图中的 HTTP 400 具体原因尚未确认。本版修复诊断和拒绝处理，尚未验证真实课堂连接恢复。详见 [错误说明](../LESSON_ENTRY_ERRORS.md)。

## 安装与验证

最低 Android 8.0，versionCode 9。先停止监测，用原交付 `YuketangHelper-Android-0.2.7-debug.apk` 覆盖安装后重启监测；与原交付 0.2.6 签名一致，无需卸载。旧错误记录保留。若仍返回 400，可在本 App 重新登录后反馈新版数值错误码。
