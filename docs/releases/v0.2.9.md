# 雨课助手 Android 0.2.9（预发布）

AI 设置改为全局共享，配置一次 API Key 后，切换或添加雨课堂账号无需重复填写。

- API Key、模型、优先顺序及失败回退由全部账号共用；移除账号后仍保留。
- 自动合并旧版各账号已有密钥，相同服务商/密钥/模型去重。优先保留当前账号的有效首选和回退开关；没有可用密钥时使用其他账号已有配置。
- 设置页新增独立的“AI 服务与密钥（全局）”入口，欢迎页也可管理。迁移后请检查优先密钥并保存。
- 保存后供后续题目使用，修改 AI 不重新连接课堂；已有调用可能完成本次请求。删除密钥会影响所有账号。
- 延续本机加密、密钥页防截图及日志脱敏。登录会话、课程选择和消息继续按账号隔离。

最低 Android 8.0，versionCode 11。先停止监测，使用原交付 `YuketangHelper-Android-0.2.9-debug.apk` 直接覆盖安装，无需卸载。原交付签名与 0.2.8 一致；自行构建或 CI 包可能不同。

137 项测试通过，Android 构建成功，Lint 0 错误、0 警告。新增 10 项迁移及多账号共用回归；未消耗真实 AI 余额。AI 共享更新尚需手机确认，未进行本版手机、模拟器或 GitHub Actions 云端验证，详见 [验证记录](../VALIDATION-0.2.9.md)。

用户已反馈 0.2.8 入课修复在其课堂成功，本版沿用该逻辑。动态二维码考勤仍未支持。
