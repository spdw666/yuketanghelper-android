# 雨课助手 Android 0.2.10（预发布）

修复答题提交中的题目编号类型丢失，以及第 3 次提交响应丢失后缺少答案复查的问题。

- 按课件接口返回的类型提交编号，保留长字符串和前导零。
- 数字编号遭遇 HTTP 400 / 50400 参数拒绝时，有条件地在下一次尝试使用同值字符串，仍受每题 3 次提交上限约束；其他明确拒绝不触发转换。
- 每次重试前检查已有答案，最后一次失败后也复查；不增加第 4 次提交，不覆盖已有答案。
- 提交未确认时显示 HTTP 状态、接口数值代码和固定校验分类，便于反馈；不显示响应原文或凭据。
- 保留所有账号共用的 AI 配置、多账号及原有入课兼容。

146 项核心测试通过，Android 构建成功，Lint 0 错误、0 警告。9 项新增回归中有 2 项已在修复前复现失败。尚未在手机、模拟器或真实课堂验证；仍需在官方端核对提交结果，详见 [验证记录](../VALIDATION-0.2.10.md)。动态二维码考勤仍未支持。
