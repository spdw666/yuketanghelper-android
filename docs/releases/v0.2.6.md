# 雨课助手 Android 0.2.6（预发布）

继续修复仍能收到课堂消息时误报“课堂消息连接持续中断”的问题。

## 更新

- 收到有效题目、点名、弹幕或课堂状态更新即确认恢复，短连接也不会继续累积中断次数。
- hello 缺失或延迟时，有效课堂事件可确认就绪；未知消息仍会等待确认并超时重试。
- 主动刷新失败时保留原凭据尝试重连；明确被服务端拒绝的凭据不作为回退，账号失效仍需登录。
- 告警区分失败阶段，保留 HTTP 状态、DNS、超时、格式异常等固定分类。
- 自动操作积压单独提示重新同步，避免将仍有消息的课堂称为网络持续中断。

## 安装

最低 Android 8.0，versionCode 8。先停止监测，使用原交付 `YuketangHelper-Android-0.2.6-debug.apk` 覆盖安装后重新开启；与原交付 0.2.5 签名一致，无需卸载。已有的错误历史会保留。

自行构建或 GitHub Actions 生成的调试包可能使用不同签名。以下校验值仅对应原交付 APK，重新构建后应更新。
