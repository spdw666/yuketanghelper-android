# 雨课助手 Android 0.2.8（预发布）

修复入课请求将接口返回的字符串课堂编号强制变成数字的问题，为反馈中的 HTTP 400 / 50400 增加有条件的一次格式兼容。

## 更新

- 保留课堂编号原始数字/字符串类型及内容，内部仍按同一课堂监测。
- 数字编号收到 HTTP 400 / 50400 且没有明确其他校验要求时，用网页端的字符串形式额外尝试一次；保持账号、站点、source 及数字内容一致。
- 已有字符串、其他拒绝、明确 CSRF/缺参/JSON/数字字段要求不转换；第二次失败继续按原有每分钟间隔重试。
- 成功后的课堂消息握手、弹幕及红包沿用被接受的编号表示。
- 失败事件显示最终编号类型和已识别的固定校验提示；补充明确的 UNAUTHENTICATED 登录失效识别。

两项本地兼容复现在 0.2.7 实现上失败，本版修复后通过。公开资料未查到 50400 的确切定义，尚不能认定已恢复用户的真实课堂连接。详见 [入课错误说明](../LESSON_ENTRY_ERRORS.md)。
