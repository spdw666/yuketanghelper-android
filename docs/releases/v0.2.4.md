# 雨课助手 Android 0.2.4（预发布）

Kotlin 原生 Android 原型。本版扩展 Android 系统与屏幕兼容性，最低支持 Android 8.0（API 26）。

## 更新

- 优化小屏、大字体、横屏、分屏、平板和折叠屏布局，以及系统栏、屏幕开孔和键盘避让。
- 新增“设置 → 后台运行与机型适配”，提供通知、电池及应用详情入口和常见品牌提示。
- 兼容 Android 8/9 的二维码保存流程，无需新增存储权限。
- 改善 WebView、TTS 和唤醒锁异常处理。
- 保留 DeepSeek、多账号、紧凑课程选择及独立通用课程设置。

## 验证与限制

0.2.4 原交付版本于 2026-10-16 完成本地编译，78 项核心测试通过，Lint 0 错误、0 警告；未进行该版本实机或模拟器验证。品牌后台运行效果仍需设备确认。

**不支持动态二维码签到。** “课堂签到成功”仅表示取得课堂连接凭据，不代表动态考勤成功；以官方端考勤记录为准。
