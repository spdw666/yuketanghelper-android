# 雨课助手 Android 0.2.5（预发布）

修复课堂消息仍正常接收时，反复显示“课堂连接暂不可用，正在重连”的问题。

## 更新

- 正常连接轮换在后台快速重连，避免错误提示刷屏。
- 持续失败才显示告警；同一轮故障每 2 分钟最多一次，稳定恢复后提示一次。
- 修复短暂连接导致重试退避不断重置的问题，补充握手超时和课堂凭据刷新。
- 区分课堂凭据被拒绝与账号登录失效，错误提示保留固定分类及数值状态码。
- 进课堂提示改为“已进入课堂；考勤状态请以雨课堂为准”。动态二维码签到仍未支持。

## 安装

安装 `YuketangHelper-Android-0.2.5-debug.apk`，最低 Android 8.0，versionCode 7。原交付包与原交付 0.2.4 签名相同；先停止监测，直接覆盖安装后重新开启。不要先卸载。旧版错误历史会保留。

自行构建或 GitHub Actions 生成的调试包可能使用不同签名。本校验值只对应原交付 APK，重新构建时应更新。
